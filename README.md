This is a challenge project built using the Rick and Morty API. The app allows users to browse characters from the Rick & Morty universe and compare two characters to see which episodes they both appeared in. It's a fun and interactive way to explore character relationships and episode data from the show.

Features
🔍 View detailed information about Rick & Morty characters

🎬 Click on two characters to find common episodes they appear in

⚡ Fast and responsive UI

🛠️ Built with Next.Js, React, Typescript, Tailwind and MUI for certain icons.
